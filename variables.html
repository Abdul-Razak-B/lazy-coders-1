Stage 1–3: Intuition & Analogy

Variables, Dynamic Typing & Scope Lifetimes

The Living Room Bulletin Board vs. Private Room: Global Scope is like a bulletin board in the shared living room — anyone in the house can view it. A Local Scope is like writing a secret on a sticky note inside your private bedroom. When you exit and close the door (the function completes), that temporary sticky note is recycled.

Plain-English Definition: A variable is a named label referencing an object in memory. Scope defines the region in your program where that variable name is recognized.

Stage 4–6: LEGB Scope Mechanics
Python 3 • scope_demo.py 
# Global Scope
forest_name = "Emerald Canopy"

def camp_site():
    # Local Scope
    campfire_temp = 350
    print("Global:", forest_name)
    print("Local:", campfire_temp)

camp_site()
# Accessing campfire_temp outside raises NameError

Stage 9–11: Diagnostic Quiz

Quick Check: What happens if you access a local variable from outside its function?

A) It converts into a global variable with value None
B) Python raises a NameError because the variable was destroyed upon exit
C) It returns the value from the last program run

✓ Correct! Local variables exist only while the function frame is on the stack.

📌 Key Takeaway

Keep variables scoped locally whenever possible to prevent side effects and keep your functions pure.
