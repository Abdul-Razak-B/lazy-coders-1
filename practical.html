The return Statement

    if score >= 85: return "A"
    elif score >= 60: return "B"
    return "Needs Revision"

Practical Lab 3

Call-by-Sharing Semantics (Mutable vs Immutable)

Python 3 • lab3_call_by_sharing.py 
def modify_data(num, items):
    num = num + 10        # Immutable: creates new local int
    items.append("🌱 Fern") # Mutable: mutates shared list in-place

trees = 100
forest_list = ["🌲 Oak"]
modify_data(trees, forest_list)

print("Global trees (Unchanged):", trees)
print("Global items (Mutated):", forest_list)
Practical Lab 4

Classes, Attributes & Objects

Python 3 • lab4_oop.py 
class ForestDrone:
    def __init__(self, drone_id, battery=100):
        self.drone_id = drone_id
        self.battery = battery

    def scan(self):
        self.battery -= 10
        return f"[{self.drone_id}] Scan complete. Battery: {self.battery}%"

drone1 = ForestDrone("Alpha-1")
print(drone1.scan())
