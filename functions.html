Stage 1–3: Intuition & Analogy

Functions, Parameters, Arguments & Return Values

The Coffee Machine: A function is like a smart coffee machine. You supply ingredients like water and beans (the arguments passed into its parameters), push start (the call), it runs its internal brewing algorithm (the body), and delivers a cup of coffee (the return value).

Plain-English Definition: A function is a named, reusable block of code that accepts inputs (arguments), performs computations, and optionally returns a result to the caller.

Stage 4–6: Syntax Breakdown
Python 3 • brew_beverage.py 
def make_beverage(drink_type, size, sugar=False):
    prepared = f"Serving 1x {size} {drink_type}"
    if sugar:
        prepared += " (with sugar)"
    return prepared

order = make_beverage("Espresso", "Medium", sugar=True)
print(order)

Stage 9–11: Diagnostic Quiz

Quick Check: What is the difference between parameters and arguments?

A) Parameters are values passed in; arguments are variables in the definition
B) Parameters are placeholder variables in the def line; arguments are real values passed during invocation
C) Parameters are print statements; arguments are return statements

✓ Correct! Parameters define the interface slots; arguments fill them at call-time.

📌 Key Takeaway

Functions prevent code duplication and let you compose complex software from modular, testable components.
